# YouSnoozeYouSolve Clock

### Inspiration

I wanted to create an alarm clock, right now i rely on my phone and i always end up snoozing until I am late. So i thought why not make snoozing a pain while also "waking" me up?

### Specifications

BOM: 
- 9x Cherry MX Switches
- 1x XIAO ESP32 C3
- 9x Blank DSA Keycaps
- 8x M3x8 Bolt
- 8x M3 Heatset
- 12x Through-Hole 1N4148 Diodes
-1x 2.25in TFT Screen
-1x 3.3V Piezo Buzzer
-1x 2.54mm 8 Pin Male Header
-8x 20cm Female-Female Jumper Wires

Others:
- Top Case.stl
- Middle Case.stl
- BLAREysys.ino
- Bottom Case.stl
